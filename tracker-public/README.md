# tracker-public

The deployable application. `index.html` is the whole thing — no build step, no
bundler, no dependencies to install.

**The hosted page is
[willowy-platypus-7b589d.netlify.app](https://willowy-platypus-7b589d.netlify.app).**
Use it rather than deploying a copy: a copy is a snapshot and receives no
later fix, security ones included. The reasoning is under
[Why one address](../README.md#why-one-address-instead-of-your-own-copy).

**The documentation lives at the [repository root](../README.md):** what it
does, the deploy button, getting started, signing in and troubleshooting, and
the optional email functions. It is kept in one place so the two cannot drift.

## Design system

Tailwind is generated ahead of time from this file's own classes and inlined
into the head, rather than compiled in the browser from a CDN — see
[Releasing a change](../README.md#versions-and-dependencies) for how to
regenerate it. Everything below is the layer on top of it.

The presentation layer is token-driven. Colour is authored in **OKLCH**, so a
ramp stepped in lightness is stepped evenly in *perceived* lightness — which
HSL cannot promise. Every token ships with an sRGB fallback under
`@supports`, generated by rendering the OKLCH through a browser rather than
matched by hand, so the two cannot drift.

Spacing and type come from named scales rather than per-component values, each
with its own variables for size, line height and tracking. Tracking is the
tell: it tightens to `-0.032em` on the display face and opens to `+0.13em` on
the smallest uppercase labels, which is what keeps an 11px caps pill legible
and a 34px heading sleek. Weights skip the mediums entirely — 400 for reading,
600 and 700 for anything the eye should land on first — so hierarchy comes
from real contrast rather than a smear of 500s. Dates, scores and every column
of figures are set in the monospace face with tabular numerals, and prose is
held to a 66-character measure.

Light mode is ultra-clean white surfaces on a cool off-white ground. Dark mode
is a separate palette, not an inversion: a neutral charcoal ramp
(`#0a0a0a` ground, `#141414` cards, `#1e1e1e` raised) where elevation is
carried by lightness rather than heavier borders, and ink stops at `#ededed`
because pure white on near-black is what causes halation. Status chips are not
saturated blocks — each carries four tokens (fill, border, text, mark) so a
desaturated tint holds crisp coloured type, every pairing clearing AA against
its own fill. Text contrast is deliberately stepped, roughly 16:1, 7:1 and 5:1
for primary, secondary and tertiary, so the eye is led rather than merely
accommodated.

Motion is confined to `transform` and `opacity`, stays under 300ms, and is
disabled entirely under `prefers-reduced-motion`. Menus and cell editors are
deliberately *not* animated: they are opened dozens of times a session, and an
entrance there reads as lag rather than polish.

Any static host serves this folder as-is. The
[`netlify.toml`](../netlify.toml) at the repository root points here, so the
deploy button needs no configuration.
